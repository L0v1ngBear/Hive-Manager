# 全站办公布局调整与验收

## 目标与边界

按用户选择的「日常办公：信息紧凑，常用操作直接可见」调整全部路由页面，沿用现有配色。范围包括导航、位置提示、操作指引、标题、工具栏、筛选、统计卡片和响应式排版。

不修改接口、权限判定、表单提交、状态流转、数据库、打印模板或部署流程。保留此前全部未提交业务改动。本次不制作服务器部署包、不提交 Git、不远程发布。

## 实现

- 桌面导航默认展开，功能名称和更多功能直接可见；保留折叠控制与原有权限禁用行为。顶栏搜索明确标注为查找功能入口，移动端菜单、搜索按钮不再显示于桌面。
- 23 个工作台页面统一显示所在分组，并提供可用键盘展开的三步操作指引。指引不触发请求、不执行业务操作。
- 工作台主内容与导航独立滚动，统一标题大小、分组间距和操作区域；窄屏工具栏换行，统计卡片紧凑排列。
- 客户筛选区补全网格布局，员工筛选区恢复已有布局类并调整网格。桌面客户筛选区从 231px 降为 123px，导出、列设置和固定操作列仍然可用。
- 库存筛选添加固定字段标签，明确区分规格上下限、剩余米数上下限、更新日期和出库顺序，保留原有参数绑定。
- 订单操作列在桌面和平板固定于右侧，避免展开导航后「详情」等入口滚出视野；手机仍使用原有卡片布局。
- 文档目录宽度、打印工具栏、手册和公告排版分别适配；登录、加入组织、密码设置、授权回调及法律页面调整页面间距。

共用布局集中在 `management-ui/src/styles/office-layout.css`，限定于 `.hive-office-ui.app-compliance-shell` 且仅作用于屏幕。现有主题 CSS 未修改，新增共用样式没有颜色、背景、阴影或透明度声明。订单固定列仅复用现有行背景和表格颜色变量作为遮挡底色；没有新增色值。

修改前后副本比对确认：修改过的现有源文件颜色字面量保持一致；业务页面脚本保持一致。导航只调整初始展开状态。

## 验证结果

- 全量前端测试：514 项，506 通过、0 失败、8 项按已有条件或浏览器开关跳过。
- 新增浏览器检查：29 个路由 × 1440 / 1024 / 768 / 390 / 320 像素，共 145 组测量与截图，全部通过。检查页面和筛选区横向溢出、标题区按钮可见性、运行时异常、键盘操作指引、导航默认名称和移动端导航。
- 带业务数据的现有浏览器测试：客户筛选、固定列和导航折叠；订单操作可见性、状态筛选和分页参数；登录模式切换与加入组织布局，全部通过。
- 订单操作可见性测试曾在展开导航后失败，固定操作列后同一断言通过，未放宽断言。
- 并行运行构建与多个浏览器时，订单、登录测试曾达到原有超时；保持超时设置不变，待其他任务结束后串行运行，3 项交互测试全部通过。
- Oxlint、ESLint（不自动修复）和 `git diff --check` 通过。
- 前端生产构建成功，生成 102 个文件的产物清单。

浏览器检查使用隔离 Chrome 会话及本地 API 测试数据，不访问真实业务账户。全路由检查主要覆盖初始页面、空态与布局，现有专项测试补充带数据交互；不代表每个弹窗和所有业务流程都已端到端重测。后端及打印数据处理代码未修改，本次未运行后端打包，也未覆盖桌面固定部署目录。

## 复跑

在 `management-ui` 目录执行：

```powershell
npm test
$env:OFFICE_LAYOUT_BROWSER='1'
node --test tests/office-layout-browser.test.js
$env:ORDER_REFERENCE_BROWSER='1'
node --test --test-concurrency=1 tests/order-reference-layout-browser.test.js tests/run-customer-layout-browser.mjs tests/run-login-layout-browser.mjs
npm run build
```

默认截图和测量保存在系统临时目录的 `hive-office-layout` 下；可通过 `OFFICE_LAYOUT_ARTIFACTS` 指定输出目录。验收代表截图已复制到本次任务的 visualizations 目录。
