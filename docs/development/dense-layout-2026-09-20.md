# 长数据分栏布局修正

目标：部门、打印队列和文档目录增多时，选择列表末尾记录仍能看到详情和操作区。保持既有配色、接口、权限、业务规则与打印纸张样式，不调整部署流程。

引用检查：organization-workspace、department-scroll 为组织页局部类；原 detail-scroll、organization-tabs 仅用于组织页。receipt-workspace/queue-list、print-workbench/task-list、document-explorer/document-tree-section 的调用均在各自页面；打印页面另有生成打印 HTML 和 print 媒体样式，本次不修改它们。共享全局样式不变。

- 组织：左右面板限高，部门、员工和职位分别滚动；标题、页签及新增职位留在滚动区外。窄屏选择部门后定位并聚焦详情，可返回部门列表。原请求防竞态及权限判断保持。
- 出库单与标签：桌面工作区限高，队列与预览分别滚动；窄屏队列限高，保持纵向排列。
- 文档：浏览器容器使用视口约束高度，目录和文件区域各自滚动。

浏览器回归 `management-ui/tests/dense-layout-browser.test.js` 使用隔离的模拟接口：60 个部门、每部门 80 名员工/60 个职位，1440/1024/390/320 宽度；60 条出库队列、50 条标签任务、80 个文档目录。检查选择末尾记录、员工和职位滚动、详情标题和操作可见、窄屏返回列表及横向溢出。组织旧版真实复现断言失败，修改后通过；文档同样先复现目录未独立滚动，再修正。

其余页面另运行 29 个路由 × 5 个宽度的基础布局回归。此项仍以初始/空数据为主，不等同于全部业务的大数据验收。上述四类页面的长数据测试不触发保存、删除、真实打印或上传。

验证：前端单元/契约测试 506 通过、9 个按环境开关跳过；长数据浏览器测试和全站基础布局浏览器测试单独启用并通过。lint、生产构建及 diff 检查作为本次交付检查。
