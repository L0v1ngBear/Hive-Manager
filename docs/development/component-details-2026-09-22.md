# 细节组件优化

## 范围与兼容边界

目标：在全站办公布局基础上，优化浮层、弹窗、抽屉以及内部表单、提示、空态、上传和操作区。保留现有青绿色配色，统一内容留白、字号层级、圆角、控件间距、焦点及窄屏可用性。用户截图对应售后物流浮层，订单页存在相同的手机号输入区缺样式问题。

非目标：接口、请求参数、权限、状态流转、数据库、通知、打印纸张、发布方式。只调整管理端展示；保留当前未提交业务改动，不制作部署包、不远程发布。

## 修改前调用方检查

- 全部 Vue 模板共 25 个 `el-dialog`、29 个 `el-drawer`、4 个 `el-popover`。涉及登录、导航、总览、手册、订单、售后、审批、考勤、质量、文档、员工、客户、设备、库存、安装、价格、组织、角色等页面。
- 基础组件包含按钮、输入、数字输入、选择器、日期/时间选择、复选/单选、开关、标签、表格、分页、表单、提示、空态、结果页、描述列表、树、上传、图片、下拉菜单、工具提示等。基础组件沿用 Element Plus 的事件、ARIA、焦点管理与业务绑定。
- `order-logistics-phone-prompt` 和 `after-sales-logistics-phone-prompt` 都有模板但无布局样式；仅分别被订单和售后引用。物流 API、手机号验证和隐藏清空逻辑保持。
- 组件样式限定于存在 `.hive-office-ui` 的管理端文档，并限定 `@media screen`。浮层通过 Teleport 挂到 body，不能只用工作台后代选择器。日期/选择弹出内容不套用业务浮层正文样式。
- 无默认标题的自定义抽屉自行管理标题、内容滚动和底部操作；不对这类抽屉强加标准正文内边距。订单与客户等既有自定义内容布局继续保留。
- 打印画布、预览纸张、标签与出库单生成 HTML 不在组件样式选择器内；不调整通用 table/input/button 元素。

## 验证计划

先用真实 Chrome 复现截图中的物流输入区贴边/按钮换行，再验证修复。检查浮层正常、加载、错误、空轨迹、长轨迹，以及弹窗/抽屉标题、长内容滚动、关闭和底部操作。覆盖 320、390、768、1024、1440 宽度及较矮窗口。运行全量前端测试、相邻布局/权限契约、lint、生产构建与差异检查。浏览器使用隔离模拟 API，不操作真实业务数据。

最终结果见下文；源码变更不等于验收完成。

## 已实施的组件修正

- 弹窗采用标题、可滚动正文、底部操作三段布局；按视口和顶部位置共同限制高度，避免保存按钮落到屏幕外。标准抽屉统一标题与页脚分隔、内边距和关闭按钮尺寸。
- 逐个核对自定义标题抽屉后，对员工、客户、订单、角色、考勤使用明确的组件类移除双重内边距。企业授权抽屉没有自行补齐内边距，因此不套用该规则。员工表单控件原本同时带原生输入框的 padding 和 Element Plus 内部 padding，本次仅修正其外层；手机表单单列显示。
- 物流浮层补齐运单、说明、输入/按钮的层级和间距，输入与按钮同高；添加输入可访问名称和窄屏可读的占位文字。保留校验、请求参数、节流和关闭清空。浮层增加上下方向备选位置，窄屏不再坚持向右弹出。
- 售后窄屏固定操作列原有宽度 320px，遮住整个数据表；仅在手机宽度取消该列的固定定位，维持水平滚动、列顺序、按钮和权限。
- Tailwind 行间距误作用于内联 `el-overlay`，使售后抽屉整体向下偏移 16px。固定遮罩的 margin 归零，不修改页面正常内容间距。
- 列设置使用项目已有 Element Plus 浮层定位能力，替代绝对定位，自动避让边缘。列移动、恢复、导出、持久化事件与数据保持；内部列表限高滚动。
- 手机日期范围选择器原宽 646px，现将两个日历纵向排列于视口内，可滚动选择起止日期，未隐藏任何月份、快捷选项或日期。
- 上传区域限制为父容器宽度，长说明和文件名可换行，修复质量记录表单被撑宽。提示、空态、结果页、描述列表、下拉菜单、表单标签、验证文字及焦点轮廓统一细节。
- 原主色规则把 `link/text` 按钮也画成实心渐变色块；现在区分主按钮和文字操作，保留原有主色与禁用状态。浏览器先复现文字按钮错误的渐变背景，再验证文字可读性；列设置 Escape 关闭后焦点返回触发按钮。
- 表格、页签、分页等沿用上一轮办公布局；图片/打印画布、导航业务、权限和提交处理未重写。组件基础样式不改变语义颜色、禁用状态及校验事件。

## 已复现的问题证据

物流提示内边距 0px 且查询按钮换行；长弹窗加顶部边距后底部越界；售后抽屉偏移 16px；列设置靠下打开时超出屏幕；手机日期面板宽 646px；质量上传长文字横向溢出。浏览器用原断言复测修复，未通过放宽边界或隐藏内容规避。

浏览器过程截图和测量位于系统临时目录 `hive-component-details`（含原始 before-results.json）、`hive-component-final` 和 `hive-component-primitives`。日期、列设置、确认框采用隔离组件页加载真实生产 CSS/组件；业务窗口从实际页面入口打开，所有业务请求均由本地模拟 API 响应。

对照修改前源码副本：订单、售后、客户编辑器的 script 内容完全一致，所有修改过的既有 Vue 文件颜色字面量一致。列设置仅将开关/定位/关闭交给既有浮层库；`findExportTable`、`handleExportTable`、`hasStructuredExport`、`handleExportAll` 函数均与修改前一致。没有修改表单提交、导出内容或权限绑定。

## 最终验收

- 全量前端测试：540 项，526 通过、0 失败，14 项按既有/新增浏览器环境开关默认跳过。相关浏览器用例另外显式启用，不把默认跳过算通过。
- 本轮组件浏览器用例 3 项通过：16 个业务窗口入口 × 1440/390/320 宽度，共 48 组；登录找回密码窗口 3 组；售后物流 3 个宽度，验证提示留白、输入与按钮、关闭清空、仅主动查询发送尾号，以及加载/失败/空轨迹/30 条轨迹。业务窗口检查包含长内容滚动后底部操作、Escape 关闭和页面运行错误。
- 独立组件页覆盖 1440/1024/768/390/320 五档宽度：长表单、标准抽屉、确认框、选择器键盘打开、日期范围真实选择、24 列列表排序、关闭返回焦点、文字按钮可读性和禁用状态。列设置进一步验证上下空间不足时仍留在视口内。
- 相邻浏览器回归 3 项全部通过：29 路由 × 5 宽度，共 145 组基础布局；组织/打印队列/文档长数据布局；通知浮层与自动刷新。
- ESLint、Oxlint：0 错误；`git diff --check` 通过。
- 前端生产构建成功，104 个产物逐项 SHA-256 与清单一致，文件数量一致，测试组件页未进入构建产物。

业务窗口入口包括员工、设备、客户、价格、库存、文档、售后、订单新建、订单预警、部门、角色、质量、考勤、审批负责人、财务审批、离职申请，以及登录找回密码。

验收边界：通用样式覆盖已清点的组件调用方，真实浏览器覆盖上述入口和状态；不等同于遍历全部弹窗的所有业务数据、角色组合和完整提交流程。订单旧物流浮层模板当前不在默认列中，没有为了测试重新暴露该列。后端未修改，本轮不运行后端打包；桌面部署目录与服务器均未改动。
