# Hive 2.0.1：页面与组件优化

发布日期：2026-09-22。基线：已交付的 `098d7243c4ffdc9826098e71cfca7eae76cf7d21`（20260921-list-hover-silent-push）。发布分支：`codex/release-2.0.1-ui`。

## 本版变化

- 全站采用紧凑办公布局，导航默认显示功能名称，页面增加位置和操作指引；统一标题、筛选、统计和操作区域的间距。
- 按预览反馈移除侧栏重复的企业卡片，保留顶部品牌区；登录左侧品牌排版沿用原版，登录页面顶部不再保留额外白边。
- 员工、客户、库存、价格、设备和标签页区分主操作与辅助操作，保留按钮权限和原有处理函数。
- 组织、文档和打印工作区支持长列表独立滚动；订单列表操作列在桌面固定可见。
- 优化物流浮层、弹窗、抽屉、表单、上传、提示、空态、日期选择和列设置，改善留白、对齐、键盘操作与窄屏显示。
- 修正会话刷新与初始路由的竞态，直接打开业务页面时等待路由就绪，避免误回首页。
- 补齐 npm 锁文件缺失的可选依赖记录，使独立发布目录可执行 `npm ci`；未升级既有依赖版本。

## 兼容边界

后端业务源码、接口、权限、数据库和部署配置与上述已交付基线保持一致。保留订单收件人、列表及详情物流查询、售后追加处理与回访、角色权限修复、页面静默更新。

订单状态、字段和处理规则沿用 2.0.0 交付基线。原开发目录中的未发布订单流程、安装派工、公众号绑定等业务改动未混入本包；相关页面只合入能与发布基线兼容的展示调整。没有清理、重置或提交原开发目录中的用户改动。

完整部署包保留现有 110 项迁移，本版不新增迁移。旧库无需重新初始化，也不要手工重复执行已成功的迁移。

## 更新方式

将桌面 `hive全新部署` 内的完整内容覆盖上传到服务器 `/root/hive`，然后执行：

```bash
cd /root/hive
bash publish.sh
```

保留服务器现有 `.env`、证书、数据库、Redis、上传文件和备份。发布脚本沿用原来的检查、备份、迁移、重启及健康验证流程。本次仅准备发布文件，没有远程部署。

已使用上一版静默更新机制的页面会在发布后重连并加载新构建；更早版本页面首次需要手动刷新。更新前保存正在编辑的内容。

如需回退，使用上一版完整部署文件并执行相同发布命令，保留服务器运行数据。本版没有新增数据库迁移。
